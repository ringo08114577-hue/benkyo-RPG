# 勉強RPG — STUDY REALM

勉強でキャラクターを育成し、ガチャ・装備強化・ターン制バトル・ダンジョン攻略を楽しむブラウザRPGの試作版です。

## 起動

GitHub Pagesを有効にすると、`index.html` をブラウザで開いてプレイできます。PC・スマートフォンに対応するレイアウトです。

公開ページ：https://ringo08114577-hue.github.io/benkyo-RPG/

## 試作版の機能

- 英語・数学・化学・物理・情報の練習問題
- 問題の追加・編集・削除、テキスト一括登録、CSV読み込み
- 勉強報酬（コイン、経験値、チケット、素材、ランダム報酬）
- キャラクターガチャ／装備ガチャ、3人編成、レベル・ステータス育成
- 6部位の装備、装備強化、全員の行動を決めてからターン開始するターン制バトル、ステージ選択式ダンジョン
- ブラウザ内の自動セーブ、JSONバックアップの書き出し・読み込み
- Supabaseを使ったアカウント登録・ログイン・クラウドセーブ（初回設定が必要）

## アカウント保存の設定

アカウントごとのクラウド保存を使うには、自分のSupabaseプロジェクトが必要です。初回設定手順は [CLOUD-SAVE-SETUP.md](CLOUD-SAVE-SETUP.md) を参照してください。セーブテーブルとユーザー別アクセス制御のSQLは [supabase-setup.sql](supabase-setup.sql) にあります。

**注意：** SupabaseのProject URLとPublishable/anon公開キーだけをブラウザに設定してください。service_role / secret keyはゲームコードに絶対に入れないでください。クラウド保存はSQL設定完了後に使えます。

## データの注意

これは開発途中の試作版です。一部のスキルツリー、戦闘バランス、素材やドット絵の種類は今後の更新対象です。ブラウザ内保存はブラウザデータ削除で失われる可能性があるため、JSONバックアップを定期的に書き出してください。クラウド保存を使う場合も、念のためバックアップを推奨します。
